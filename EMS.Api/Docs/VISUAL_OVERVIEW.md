## ?? API Endpoints (41 Total)

### Authentication (8 endpoints)
```
POST   /api/v1/auth/register              New user registration
POST   /api/v1/auth/login                 User login
GET    /api/v1/auth/profile               Get current user
POST   /api/v1/auth/change-password       Change password
POST   /api/v1/auth/refresh-token         Refresh access token
POST   /api/v1/auth/logout                Logout (blacklist token)
POST   /api/v1/auth/forgot-password       Forgot password
POST   /api/v1/auth/reset-password        Reset password
```

### Students (8 endpoints)
```
GET    /api/v1/students                   Get all (paginated)
GET    /api/v1/students/{id}              Get by ID
POST   /api/v1/students                   Create
PUT    /api/v1/students/{id}              Update
DELETE /api/v1/students/{id}              Delete
GET    /api/v1/students/search/{term}     Search
GET    /api/v1/students/department/{deptId} Filter by dept
GET    /api/v1/students/probation         Probation list
```

### Courses (8 endpoints)
```
GET    /api/v1/courses                    Get all
GET    /api/v1/courses/{id}               Get by ID
POST   /api/v1/courses                    Create
PUT    /api/v1/courses/{id}               Update
DELETE /api/v1/courses/{id}               Delete
POST   /api/v1/courses/{courseId}/enroll/{studentId}  Enroll
GET    /api/v1/courses/{courseId}/students           Students list
GET    /api/v1/courses/{courseId}/available-seats    Available seats
```

### Grades (9 endpoints)
```
GET    /api/v1/grades                     Get all
GET    /api/v1/grades/{id}                Get by ID
POST   /api/v1/grades                     Create
PUT    /api/v1/grades/{id}                Update
DELETE /api/v1/grades/{id}                Delete
GET    /api/v1/grades/student/{studentId} Student grades
GET    /api/v1/grades/course/{courseId}   Course grades
POST   /api/v1/grades/{id}/submit         Submit for approval
GET    /api/v1/grades/student/{studentId}/gpa  Calculate GPA
```

### Attendance (8 endpoints)
```
GET    /api/v1/attendance                 Get all

DELETE /api/v1/attendance/{id}            Delete
GET    /api/v1/attendance/student/{studentId}/course/{courseId}  Period
```
